# Private dataset contract

All files below belong in a private directory such as `data/verified_cohort/`.
Never upload actual filled tables or epoch arrays just because IDs are pseudonyms.

`dataset.json`: `{"label_source":"independent_clinical_diagnosis"}` with optional
provenance notes. Use `synthetic_demo` only for artificial software test datasets.
The declaration is checked, but its truth cannot be inferred by software.

`subjects.csv`: columns `subject_id,label,epochs_file`, one row per actual person.
Label is 0/1. `epochs_file` is relative to the dataset directory and cannot escape
it. Subject IDs must be globally unique across sites/folders; do not use an
ambiguous filename alone. No participant name, phone number or birthdate.

`features.csv`: `subject_id` plus one finite scalar column per measured feature.
One row per subject, exact subject set equality; order is matched explicitly by
subject ID. Repeated trials do not become independent rows. Missing values fail
validation rather than being silently imputed using the whole cohort.

`feature_schema.json`: maps feature names to records with `modality` (Behavior/ERP/TF/PAC/dwPLI)
and `testing_family` (e.g. TF/Theta/N1). Simple modality strings are accepted for
synthetic demos, which use modality-level families. Include only prespecified predictors. Do not put diagnosis scores,
case/control labels, filenames, collection-order proxies or participant IDs in
the predictor matrix. At least one behavior and one EEG feature are required.

Epoch NPZ: keys `epochs` (float trials×channels×samples), `sfreq` (Hz), `channels`
(string array). Same montage order and time grid for all subjects; >=2 finite
trials and >=64 time samples. Loader rejects byte-identical EEG for different
people. Arrays from MNE preparation are in volts. Demo arrays are dimensionless.

The continuous preprocessing manifest additionally requires `clinical_label`,
`raw_file` (relative to manifest location), plus optional JSON `bad_channels` and
`bad_segments`. ICA exclusions are in the bound `review.json` generated by
`ica-review`; `prepare` requires `--ica-directory`.
Measured behavior whitelist must exactly match the configuration; compute IES
from measured RT/accuracy under a documented valid-trial policy outside this
package. No raw logs or clinical labels are inferred from signal amplitudes.
