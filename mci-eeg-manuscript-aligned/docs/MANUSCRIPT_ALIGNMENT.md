# 手稿方法与实现对应表

本表对应提供的《英文手稿1.docx》的方法描述及用户确认的 M1/M2 参考、眼动/眼跳/
心跳 ICA 剔除。代码参数不是对既有研究执行情况的自动证明。

| 项目 | 当前实现 | 需注意/确认 |
|---|---|---|
| 参考 | M1/M2 平均参考 | 两个参考通道必须真实存在 |
| ICA 通道 | 全部可用头皮 EEG，排除乳突和辅助通道 | 实际帽子通道名、类型、位置需核对 |
| EEGNet | 独立配置的 12 个核心电极，0–1 s | 不随 ICA 通道数改变 |
| ICA 审核 | 导出地形图、序列、PSD、EOG/ECG 候选评分；人工批准后复用同一分解 | 软件不自动确认剔除 |
| ICA 随机参数 | MNE 1.13+ 用 rng，旧版兼容 random_state | 本地实际测试为 MNE 1.11；新版分支作接口模拟测试 |
| 滤波/分段 | 0.1–30 Hz、48–52 Hz 陷波、−0.5–1 s、−0.5–0 s 基线 | ICA 拟合使用 1–30 Hz 副本，应写入方法 |
| 伪迹阈值 | 绝对幅度 ±80 μV | 不等同于 160 μV 峰峰值 |
| ERP | 6 个成分×区域组合，各含平均波幅和峰潜伏期 | 合计 12 项 |
| TF | 各试次功率→跨试次平均→基线 dB→ROI/频段/窗口均值 | 1–30 Hz、反射填充；低频边缘估计需谨慎 |
| EEG 筛选 | 训练折双侧均值差置换＋家族 BH＋效应量排序＋0.70 相关去冗余 | 配置 5,000 次；稿件须明确训练内次数 |
| 特征域上限 | 配置支持 ERP/TF/PAC/dwPLI 各域固定上限 | 手稿未列数值，当前 null 表示不设上限，待确认 |
| P1 行为筛选 | 当前 Welch＋BH | 稿件只写组间比较，应确认具体检验 |
| P3/P6 行为 | ACC、RT、IES 全保留 | 不参与共同 EEG 的显著性筛选或相关性删除 |
| P3/P6 Stacking | 内层概率＋处理后原始特征 passthrough；元 LR C=1 | 表征外层训练拟合，内层不是完整表征的独立验证 |
| EEGNet 早停 | 受试者水平训练/验证划分，训练子集标准化 | 默认验证比例 0.25、patience=10，应确认实际方案 |
| PCA | 外层训练拟合，固定 8 维 | 数据不足时报错，不静默改变维数 |
| PAC | 全分段 Hilbert 后取短窗、试次 MI 平均、200 次相位时移 | 稀疏箱置零会有偏倚；代理也对试次取平均，zMI 定义需明确 |
| dwPLI² | 电极对计算后 ROI 对平均，默认汇总试次×时间 | 时间相关性限制；保留负估计，与截断到 0–1 的实现不同 |
| SHAP | 独立全数据 Stacking 解释模型，单网络全局 PCA | 近似 SHAP、前十条形/summary 图、Spearman/BH 表；不是 OOF 模型解释 |

PAC 与 dwPLI² 的短窗模式是可复现的描述性估计，不能因“与稿件一致”就免除
估计偏倚和敏感性验证。`dwpli_estimator=trial_mean` 可用于另行报告的敏感性分析，
不是与 pooled_time 完全等价的替代。不得把两种估计量的数值混在一张未注明的方法表中。

本版本实现的是上述分类与完整流程置换，以及说明中的特征和解释流程。
稿件中的人口学表、配对敏感性统计、DeLong、Youden 阈值指标、置信区间、校准/DCA、
神经网络时空显著性图不在当前命令的输出范围；不能据此宣称已复现整篇文章。
